# 阶段 3 合成评测集

`dataset.json` 是固定版本的标注集；`sources/` 保存对应资料。
全部内容为本项目自生成的公开替代样本，按 CC0-1.0 提供，不包含用户教材。
重建：在 backend 运行 `python -m scripts.build_stage3_dataset`。

共 63 个独立问题：同义表达、术语、试题、多证据、无答案、边界各 10 题，
另有 2 个英文表格问题和 1 个公式问题。dev 32 题、holdout 31 题。
主干知识类别按奇偶固定划分，跨章节组合保持同一划分；同一边界类别的两道不同问题
分属两集。两集仍使用同一合成资料库，适合开发回归，不能推断到陌生教材的泛化能力。

每条 expected 包含证据单元 ID、文档键、章节和原文锚点。运行时映射到新 chunk ID，
同一证据被重叠片段命中多次只计一次。期望证据集不是穷尽所有合理替代证据的人工标注，
命中分数可能保守。跨章节题需覆盖列出的两个证据单元。

参考答案来自样本自身的明确断言或练习答案，状态为
`programmatic_from_authored_fixture`，不标记为人工核验。所有事实性、语义引用、自然语言拒答
审核初始状态均为 pending。`human_review.csv` 应由实际审核者填写并注明姓名/日期。

边界资料包括其他账号、其他课程、未选中、failed 和 deleted 状态。
检索测试保留这些资料/片段以检验查询过滤；API 对显式选择越权/非 ready 资料应返回 404。
实际物理删除和重建可见性另由真实 PostgreSQL 集成测试覆盖。

图表与扫描件二进制专项样本由 `scripts.evaluate_parse_quality` 生成，独立报告解析损失，
不混入主标注集平均分。它们是简单样本，不能代表复杂图表、数学排版或真实扫描噪声。
