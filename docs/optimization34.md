# 优化阶段3、4：测量契约与上下文实验

## 实验前固定的规则（2026-10-30）

本轮仅实施 O07、O09、O05，不实施整轮上下文预算或收尾策略。
阶段3测量通过后，才运行以下阶段4对照。规则不根据保留集结果调整。

- 基线：当前900字符切块，无短段聚合、标题配对、相邻补取。
- 候选：仅开启短段聚合、仅开启已有标题配对、仅开启相邻补取；不组合。
- 聚合：两侧均小于160字符，总长度不超过900；仅同章节/幻灯片普通正文；不跨表格、题目、答案、PDF页。
- 补取：每个命中前后各一个位置，整次最多新增两个来源，总正文仍受现有检索字符上限限制；同账号/课程/选中且就绪的非PDF资料，同章节和幻灯片。
- 开发样本用于边界回归；冻结后生成不同主题的自制保留资料与问题，记录文件与配置指纹，不依据结果调参。
- 覆盖Markdown、TXT、Word、PPT的标题、条件、多问、相邻章节、题答、表格说明；PDF与无答案、删除/未选择资料作边界回归。
- 程序检查：原文保留、位置/章节、题答隔离、范围隔离、真实输入来源及引用快照一致。
- 证据完整率按预先列出的必要事实逐题统计；引用存在不等同语义支持。答案完整性、引用语义支持和无答案放行需另评，程序匹配不能替代。
- 采用门槛：边界回归零新增失败；保留集必要事实完整题数严格高于基线；答案完整性和引用支持不下降、无答案误放行不增加；已知输入Token及暖态中位延迟均不超过基线1.25倍。未知指标不视为通过，失败题保留在分母。
- 小样本只给逐题结果，不报告容量/P95，不宣称统计显著。无真实质量对照或指标不完整时保留原默认。
- 本轮外部模型请求硬上限60（包含重试），本地FastEmbed不计入外部请求；模型替身结果单列。

## 记录口径

`messages.measurements`（迁移0009）为空表示旧记录口径未知，不重算历史。
新记录version=1区分逻辑调用、实际HTTP尝试、工具调用及本地Embedding。
usage的complete/partial/missing/no_calls区分完整、部分、缺失及未调用；known_*只是小计。
失败重试的usage未知使整轮总量保持未知。缓存/推理Token是供应商总量子集，不重复相加。
当前未配置可信的版本化价格，费用保持未知；无调用为不适用，不伪造账单。

阶段以单调时钟记录区间，存在嵌套（如检索中的本地Embedding），不可将所有区间相加。
agent为模型决策/生成，query_rewrite/review/repair/recheck分别记录，另记录检索、外部工具及最终持久化。
旧first_token_ms为历史口径，新记录表示首个有效模型输出（含推理或工具参数，并非最终答案首字）；generation_ms为agent调用等待累计。
server_first_body_ms为已核验正文首次交给SSE迭代器的时间；不保证网络送达。
浏览器通过performance.now和requestAnimationFrame记录首次正文渲染机会，发出studyrag:answer-visible事件；不是精确屏幕绘制测量，也不和服务端时钟相减。
load_conditions=unmeasured时未区分冷暖/并发，不据此比较性能。

生产默认保持不变，已有资料/引用不重建。候选只作用于显式新建资料和新请求；关闭开关不重切已有块，应保留版本并重新上传隔离副本比较。
